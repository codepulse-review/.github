# Security policy

If you think you've found a security issue in CodePulse Reviews or any repository in this organisation, please email **security@codepulsehq.com** rather than opening a public issue.

Include what you found, how to reproduce it, and what you think the impact is. We'll acknowledge your report promptly and keep you updated until it's resolved.

Please don't test against other customers' data or run anything that degrades the service.
