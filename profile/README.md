## What you get

- **A real review on your own PR.** Inline comments on bugs, security, logic and architecture. Praise stays in the summary, so nothing blocks a merge for no reason.
- **Depth on mobile code.** Swift and Kotlin reviews are backed by a language server, not just text matching. TypeScript and Python get the same treatment.
- **One-click fixes.** Hit *Fix issues* in Slack and the problems it found are pushed to your branch.
- **Slack, when you want it.** Post a PR link in a channel and the review comes back in the thread, with buttons to fix or re-review.

## Try it in three minutes

1. [Install the GitHub App](https://github.com/apps/codepulse-review) on a repository.
2. Open or update a pull request.
3. Read the review on the pull request, usually within a couple of minutes.

No Slack needed to start. You can add it after your first review.

## Repositories

| Repo | What it is |
|---|---|
| [`review-action`](https://github.com/CodePulseHQ/review-action) | GitHub Action that triggers a review once your CI passes. No secrets to set up |
| [`tideline`](https://github.com/codepulse-review/tideline) | A small public app with planted bugs in Swift, Kotlin and TypeScript. Open its pull requests to see real reviews |
| [`babysit-prs-plugin`](https://github.com/CodePulseHQ/babysit-prs-plugin) | Claude Code plugin that watches your PRs and fixes review comments and failing CI |
